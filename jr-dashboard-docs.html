Emory Woods — Leasing Dashboard

User Guide  ·  July 2025

This guide explains how to use the Leasing Dashboard at /jr-dashboard. It covers logging in, finding units, editing unit details, managing carports, and exporting a printable report. No technical knowledge is needed.

1. Logging In

When you open the dashboard, you will see a login screen asking for an Access Code. Type the code you were given and press Enter or click the Enter button.

Staying logged in: The dashboard remembers your login in the browser. You will not need to enter the code again unless someone changes it or you use a different browser/device.

2. The Dashboard Layout

After logging in, you will see two main areas:

  • Top bar — search box, unit type filter, and the Map / Table toggle and Export PDF button.
  • Main area — either the property map (default) or the full unit table, depending on the toggle.

Map View vs. Table View

Use the Map / Table toggle buttons in the top-right corner to switch between views.

ViewBest for
MapSeeing the property visually, clicking a building to drill into its units, switching between Vacant / Notices / All Units / Renewals / Carports.
TableSeeing all units (or all carports) in a spreadsheet with sort and filter on every column.

3. Map View — Navigating Buildings

The map shows colored pins for each building. Each pin displays how many Vacant units and pending Notices the building has.

1
Click a building pin to select it. A gold bar appears on the right panel showing the building address.
2
The right panel now shows only units from that building, filtered by the active tab.
3
Click ✕ Clear in the gold bar to go back to viewing all buildings.

The Tabs (right panel)

There are two main sections — Apartments and Carports — with a toggle at the top of the panel. Under Apartments, there are four tabs:

TabShows
VacantUnits currently empty (no tenant).
NoticesUnits where the current tenant has given notice to move out.
All UnitsEvery unit in the selected building (or all buildings).
RenewalsOccupied units whose 12-month lease is expiring within 30 days.

Filter Chips

Below the tabs are small filter buttons. Click one to narrow the list to only units that have that flag set:

  • Needs Maint. — has maintenance items listed.
  • 13-Mo Promo — marked as eligible for the 13-month promotion.
  • Ready for Tour — unit is ready to show to prospects.
  • Locks Changed — lock has been changed.
  • Maint. Done — all maintenance is marked complete.

Multiple chips can be active at once. Click ✕ Clear to remove all chips.

4. Editing a Unit

Click any unit card in the panel (or any row in Table View) to open the Edit Unit form.

Status

Select the unit's current situation using the three buttons at the top of the form:

StatusWhen to use
OccupiedA tenant currently lives there and has not given notice.
VacantThe unit is empty.
NoticeThe current tenant has given notice they are leaving.

Tenant Information

  • Tenant Name — full name of the current resident.
  • Contact — phone number or email.

Unit Details

  • Unit Type — Studio, 2BR, or 3BR.
  • Condition — Classic or Renovated.
  • Rent — the rent amount (e.g. $1,850). Type freely.
  • Lease Type — Month-to-Month or 12-Month Lease.

Dates

FieldWhat to enter
Last Lease Renewal / Move-InThe date the current tenant moved in, or the date their most recent 12-month lease started.
Notice DateThe date the tenant told you they are leaving (only relevant for Notice status).
Lease To / Move-OutThe date the lease ends or the tenant plans to move out. For 12-month leases, this fills in automatically from the move-in date.
12-Month Lease auto-calculation: When you set Lease Type to "12-Month" and enter the Move-In date, the Lease To date is automatically set to the last day of that same month one year later. You can override it manually if needed.

Maintenance

Click the maintenance tags to mark what the unit needs: Paint, Maintenance, Cleaning, Flooring. Multiple items can be selected at once.

When all work is done, click Mark Done. The tags will show with a strikethrough to indicate completion.

Additional toggles in this section:

  • Locks Changed — toggle on when the unit's locks have been rekeyed.
  • Ready for Tour — toggle on when the unit is presentable for prospects. (Only shown for Vacant or Notice units.)
  • 13-Month Promo — toggle on to flag this unit as eligible for the 13-month lease promotion.

Notes

A free-text area for anything else you want to record about the unit.

5. Special Unit Actions

Adding a Future Tenant (Vacant or Notice units)

When a unit is Vacant or Notice, you can record who is moving in next before they actually arrive.

1
Scroll to the bottom of the edit form and click + Add Future Tenant.
2
Enter the future tenant's name and their scheduled move-in date.
3
Save. The unit will now show a Vacant (Rented) badge on the card, and a blue "Future:" label with their name and move-in date.

Marking a Tenant as Moved In

Once the future tenant has actually moved in:

1
Open the unit's edit form.
2
In the Future Tenant section, click Moved In?.
3
The form will automatically set the status to Occupied, copy the future tenant's name to Tenant Name, set their move-in date, set the lease to 12-month, and clear all maintenance flags.
4
Click Save Unit.

Marking a Tenant as Moved Out (Notice → Vacant)

When a tenant with Notice status has physically left:

1
Open the unit's edit form.
2
Next to the Move-Out date field, click the Move Out button.
3
The form sets the unit to Vacant, saves the previous tenant's name and move-out date as a historical record, and clears all current tenant fields.
4
Click Save Unit.

6. Searching for a Unit

The search bar at the top works across all units at once, regardless of which building or tab is selected.

You can search by:

  • Unit number (e.g. 01 or 12)
  • Tenant name (e.g. Johnson)
  • Building code (e.g. 2194 ND)
  • Street address (e.g. Webster Drive)
  • Notes text
  • Combined building + unit shorthand (e.g. 2194nd01)

Results appear as a list overlay. Click any result to immediately open the edit form for that unit. Press Escape or click ✕ to close the search.

Type filter: Next to the search bar, there is a dropdown to filter by unit type (All Types / Studio / 2BR / 3BR). This applies to both search results and the main panel.

7. Table View

Switch to Table View using the Table button in the top-right. This shows all units in a spreadsheet format.

At the top of the table there are two tabs:

  • Units — all apartment units.
  • Carports — all carport spaces.

Sorting

Click any column header to sort by that column. Click again to reverse the sort direction.

Filtering

Below each column header is a filter box. Type in it to narrow the rows to only those matching your input. For Yes/No columns (like Maintenance, Lock, Tour), a dropdown lets you filter to only rows where the flag is checked or unchecked.

To clear all filters, click the Clear all button that appears when any filter is active.

Clicking a row

Clicking any unit row opens the same Edit Unit form described in Section 4.

8. Carports

Viewing Carport Spaces

In Map View, click the Carports section toggle (above the tabs) to switch the right panel to carports. You can also click a carport marker on the map directly.

In Table View, select the Carports tab at the top of the table. The summary bar shows: X available · Y tenant · Z office · W shop · N total.

Carport Status Types

StatusMeaning
AvailableSpace is unoccupied and available to lease.
TenantRented to a current Emory Woods apartment tenant. The tenant's name and unit are linked automatically.
OfficeReserved for the leasing office.
ShopReserved for the maintenance shop.
ExternalRented to someone who is not an Emory Woods tenant (e.g. a neighbor).

Assigning a Carport Space

1
Click any row in the Carports table (or click a carport pin on the map). A modal opens showing all spaces for that carport area.
2
Find the space you want and click Assign (or Edit if it already has an assignment).
3
Select the assignment type: Tenant, Office, Shop, or External.
4
Fill in the fields that appear:
  • Tenant — pick the unit from the dropdown. Tenant name and address fill in automatically. Add a rental date and rate.
  • External — enter the person's name and phone, plus rental date and rate.
  • Office / Shop — only a notes field appears.
5
Click Save.

Removing a Carport Assignment

In the carport modal, click Unassign next to the space. This clears all tenant info and marks the space as Available again.

9. Lease Renewal Alerts

The dashboard automatically watches for 12-month leases that are expiring soon. When a lease is within 30 days of its end date, the unit will:

  • Show an Lease ends in Xd badge on its card.
  • Show a warning banner inside the edit form.
  • Appear in the Renewals tab.

If the lease has already expired, the badge turns red and says "Lease expired."

How the lease end date is calculated: If no Move-Out date is set manually, the dashboard calculates it as the last day of the same month, one year after the Move-In date. For example, a move-in of October 24, 2024 gives a lease end of October 31, 2025.

10. Exporting a PDF Report

Click the Export PDF button in the top-right corner. A new browser tab opens with a printable report showing:

  • Left side: all Vacant units with their type, condition, rent, any future tenant, and maintenance flags.
  • Right side: all Move-Out Notices with move-out date, current tenant, and maintenance flags.

The browser's print dialog will open automatically. Select Save as PDF as the destination to save a PDF file, or choose a printer to print directly.

Landscape format: The report is designed for landscape (horizontal) paper orientation. This should be set automatically, but if not, switch to landscape in the print dialog before printing.
