B
Initial documents — Deposit Receipt & Welcome Letter
⏱ 5 minSame steps for both
  1. Open the dashboard → search the building → scroll down → click Create Document.
  2. Document Type → choose Deposit Receipt (then repeat with Welcome Letter).
  3. Fill out everything: base rent, water/sewer, security deposit, and pet or liability to landlord insurance.
  4. Leave Adults / Children alone unless they need changing.
  5. Click Deposit Receipt (or Welcome Letter).
  6. Right-click the file → Open With Preview → Print.

The move-in packet

Build the tenant's folder. Compare with the Move-In Packet Master — the grey folder — so nothing is missing.

What goes in the folder

  • Inspection Move-In form PaperFill out on the typewriter. Deadline = 3 days after move-in.
  • Map PaperHighlight the leasing office and their apartment. Write LAUNDRY CODE 2628 at the top.
  • Emergency after hours PaperFrom the papers drawer.
  • Information packets PaperMaster copy in the file drawer.
  • Policy Letter DashboardGenerate — steps on the right.
  • Renters Insurance DashboardGenerate — steps on the right.
  • Prox Card agreement Paper
  • Vehicle registration form Paper
Inspection form deadline is 3 days after move-in — not 3 days from today. The second key depends on this form.

Generate from the dashboard

Policy Letter
⏱ 30 sec
  1. Search building or tenant name → scroll down → Create Document.
  2. Document Type → Policy Letter.
  3. Double-check name and Move-In Date.
  4. Click Policy Letter → right-click → Open With Preview → Print.
Renters Insurance
⏱ 30 sec
  1. Search building or tenant name → scroll down → Create Document.
  2. Document Type → Renters Insurance.
  3. Double-check name and Move-In Date.
  4. Click Renters Insurance → right-click → Open With Preview → Print.
Wrong name or date on the form? Fix the apartment's Future Tenant first, then start the document again.

D
One week before move-in
⏱ 10 min7 days out
  1. Email the Pre Move-In email to the tenant. Template: Google Docs → Email Template on the office computer.
  2. Adjust the utilities line for the apartment type (table below).
  3. Check the lease — has it been sent? Has it been signed?
Apartment typeUtilities the tenant sets up
Renovated StudioElectric only
ClassicElectric + Gas
Lease not sent yet? Send it now — on move-in day a signed lease is check #1.
E
Move-in day · Tenant in the leasing office
Four checks before any key
  • 1 · Lease signed
  • 2 · Proof of utilities account — electric, plus gas if Classic.Write down the start date and account number.
  • 3 · Renters insurance decisionThird-party provider → ask for the declaration page.  AppFolio → tell them it is $13/month.
  • 4 · Move-in rent — check or money order.
1
All four ticked → give ONE key only. Tell the tenant: bring back the completed Inspection Move-In form to receive the second key.
Any of the four missing → no key yet. Explain what's missing and when they can come back.
F
After move-in
⏱ 5 minSame day
  1. Give the security deposit check and move-in rent check to the manager.
  2. If possible, update the tenant's profile tags: vehicle tag, vehicle permit number, prox card number.
