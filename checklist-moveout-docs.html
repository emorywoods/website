A
Stage A · When the tenant gives notice

Notice

Get the notice in writing, check the 30 days, mark the apartment as Notice in the dashboard, then move the paper files.

A1
Notice form & dashboard
⏱ 5 minSame day as notice
  1. Tenant asks to move out → ask: filled out the Move-Out Notification? If not, give one — by email, or a paper copy from the paper drawer.
  2. Notice received → check the move-out date is at least 30 days after the notice date.
  3. Open the dashboard → search the building → click the apartment.
  4. Set Status to Notice. Fill Notice Date and Move-Out date.
  5. Click Save Unit.

A2
Move the paper files
⏱ 10 minManager's office
  1. Grab the apartment file for that apartment number from the manager's office.
  2. Grab a new empty file — this becomes the tenant move-out file.
  3. Move the tenant's papers from active tenant to notice tenant (the new file). Put the apartment file with the vacant apartment files.
  4. Type the label on the typewriter — name on line 1, address on line 2 — and stick it on the new file.

Stage C · After the manager inspects

After inspection

Make the refund request, get signatures, copy, and sort the papers.

C
After inspection — Request For Refund of Security Deposit
⏱ 15 minAfter manager inspects
  1. Manager finishes inspection → on the office computer open Desktop → Emory Woods Documents → RequestForRefundOfSecurityDeposit.
  2. Fill in the tenant's information and the condition of the apartment.
  3. Print. Ask the manager to sign the refund request and the move-in inspection form.
  4. Copy the signed refund request 2 times → 3 total.
  5. Sort the papers — see the table.
